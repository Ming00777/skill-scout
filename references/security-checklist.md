# 安装前安全审计清单

Skill 不只是说明文档——它是**用你的权限执行的代码**。`scripts/` 里的脚本和 Agent 拥有同等权限，能读你的 SSH 私钥、能往外发文件。Skill 市场出过真实的恶意包事件，所以这一步不能省。

## 什么时候必须扫

- 候选带 `scripts/` 目录 → **必扫**
- SKILL.md 正文里出现网络请求、文件读写、shell 命令 → **必扫**
- 纯 markdown、无脚本、无命令 → 快速扫一遍即可，在推荐卡里标"无脚本"

## 高危信号（命中任意一条：不推荐，或在卡片里显著警告）

| 信号 | 风险 |
|---|---|
| `curl ... \| bash` / `wget ... \| sh` | 远程代码执行，内容不可见 |
| 读取 `~/.ssh/`、`~/.aws/`、`.env`、`~/.config` | 窃取凭据 |
| `base64 -d`、混淆字符串、动态 `eval` | 隐藏真实意图 |
| 向未知域名 POST/上传文件 | 数据外发 |
| `rm -rf`、`chmod 777`、写系统目录 | 破坏系统 |
| 安装时请求 API key 却不说清用途 | 凭据泄露 |
| 要求关闭安全检查、`--no-verify`、禁用沙箱 | 主动绕过防护 |
| 脚本事先被编译成二进制、无源码 | 无法审计 |

## 扫描做法

1. 先看结构：`gh api "repos/{owner}/{repo}/git/trees/{branch}?recursive=1"` 列出全部文件
2. 逐个读 `scripts/` 下的文件，重点看网络请求和文件读写
3. 没时间细读就用关键词快扫：

```bash
grep -rnE "curl|wget|eval|base64|ssh|aws|\.env|rm -rf|chmod" <skill目录>
```

4. 命中关键词不一定有问题，**要读上下文判断意图**——下载依赖是正常的，把 `~/.ssh/id_rsa` 传出去不是

## 审计结果写进推荐卡

```
安全提示：含 2 个 Python 脚本。已扫描：无外发请求、无凭据读取、无混淆。
         1 处 curl 用于下载依赖，来源为官方域名。
```

或：

```
安全提示：⚠️ 发现 curl | bash 远程执行，且目标域名非官方。建议不要安装。
```

## 铁律

**审计没做完，不许说"可以装"。** 说"看起来没问题"之前，必须真的读过脚本。
